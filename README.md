# Vidas Interrompidas · Rio de Janeiro

## Português

Memorial interativo em 3D que reúne 56 casos reais de vítimas da violência armada na Região Metropolitana do Rio de Janeiro, organizados por idade dos 3 aos 73 anos.

> O processo de coleta de mais informações ainda está em andamento.

### Como executar
```bash
node server.js
```
Acesse `http://localhost:3000` (no Windows, também é possível abrir clicando em `iniciar.bat`).

### Referências
- **Inspiração visual:** [Life After · The Pudding](https://pudding.cool/2026/10/lifeafter/)
- **Fontes:** Instituto Fogo Cruzado, Futuro Exterminado, G1 Rio, Agência Brasil, UOL, O Dia, R7 e Redes da Maré
- **Trilha sonora:** Milton Nascimento, *"Francisco"*

## English

Interactive 3D memorial documenting 56 real cases of victims of armed violence in the Rio de Janeiro Metropolitan Area, arranged by age from 3 to 73 years old.

> The process of gathering more information is still ongoing.

### How to run
```bash
node server.js
```
Open `http://localhost:3000` (on Windows, you can also run `iniciar.bat`).

### References
- **Visual inspiration:** [Life After · The Pudding](https://pudding.cool/2026/10/lifeafter/)
- **Sources:** Instituto Fogo Cruzado, Futuro Exterminado, G1 Rio, Agência Brasil, UOL, O Dia, R7, and Redes da Maré
- **Soundtrack:** Milton Nascimento, *"Francisco"*
